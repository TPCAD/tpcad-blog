# 树

**树**是一种抽象数据类型或是实现这种抽象数据类型的数据结构，用来模拟具有树状结构性质的数据集合。它是由 n（n > 0）个有限节点组成一个具有层次关系的集合。

```language
         a
       /   \
      /     \
     b       c
   / | \     | \
  d  e  f    g  h
 /   |         / \
i    j        k   l
```

树具有以下特性：

- 每个节点都只有有限个子节点或无子节点
- 有且仅有一个节点没有父节点，称为根节点
- 非根节点有且仅有一个父节点
- 非根节点可以分为多个不想交的子树
- 树里面没有环路

## 树的术语

- 父节点：若一个节点含有子节点，则称该节点为其子节点的父节点
- 子节点：一个节点含有的子树的根节点称为该节点的子节点
- 兄弟节点：具有相同父节点的节点互为兄弟节点
- 叔节点：与父节点是兄弟节点的节点
- 节点的度：节点含有的子树个数
- 树的度：树中最大的节点度
- 叶子节点：度为零的节点
- 节点的层次：根节点为第一层，根节点的子节点为第二层，以此类推
